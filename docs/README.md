# docs/

This folder is for **end-user documentation** for the `Spotlight Theme 2026` theme.

It is intended for:

- Setup guides (how to install and configure the theme)
- Editor guides (how to use the block editor with this theme)
- Client-facing theme usage notes
- Screenshots and visual references
- Style guide and brand usage documentation
- FAQ and troubleshooting

---

## What Does Not Belong Here

- Developer reports → these live in `.github/reports/`
- Task lists → these live in `.github/tasks/`
- AI prompt files → these live in `.github/prompts/`
- Code documentation → keep in code comments and README files

---

## Naming Conventions

Use descriptive filenames. Examples:

- `setup.md`
- `editor-guide.md`
- `style-guide.md`
- `faq.md`

---

## Notes

Keep documentation human-readable and focused on people who use the theme, not people who build it.
