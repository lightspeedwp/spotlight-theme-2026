# .agents/agents/

This folder contains agent persona definitions for this repository.

---

## What Is an Agent Persona?

An agent persona describes a specialist role that an AI agent can adopt when working in this repository.
Personas help ensure consistent, expert behaviour across sessions and tools.

---

## Available Personas

| File                    | Persona                           |
|-------------------------|-----------------------------------|
| `theme-architect.md`    | WordPress block theme architect   |

---

## Using a Persona

Reference a persona file at the start of an AI session:

```
Please adopt the persona described in .agents/agents/theme-architect.md
for this session.
```

---

## Adding a New Persona

1. Create a new `.md` file in this folder.
2. Define the persona's role, expertise, priorities, and behaviours.
3. Update this README with the new entry.
